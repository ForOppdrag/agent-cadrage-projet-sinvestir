# Roadmap

## MVP

- Workflow n8n en 5 noeuds.
- Interface Next.js de saisie du brief.
- Route API qui transmet le brief au webhook n8n.
- Prompt systeme structure.
- Notification du referent interne.

## Version avancee

- Supabase pour stocker les briefs et fiches projet.
- Interface dashboard pour suivre les statuts.
- Historique des briefs et recherche.
- Slack pour notifier les equipes sur des donnees filtrees.
- HubSpot pour relier demandes, comptes et opportunites.
- WooCommerce pour analyser les besoins lies au tunnel de vente.
- Authentification des utilisateurs internes.
- Monitoring des executions n8n.
- Journalisation et audit logs.
