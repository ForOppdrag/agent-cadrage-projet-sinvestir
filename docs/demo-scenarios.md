# Scenarios de demonstration

## 1. Automatiser la facturation interne

Brief : l'equipe operations veut automatiser la consolidation mensuelle des factures internes aujourd'hui geree par tableur.

Points montres :

- reformulation du besoin ;
- MVP avec collecte, verification et notification ;
- risques de qualite des donnees ;
- questions sur les sources comptables et les validations.

## 2. Creer un dashboard de pilotage

Brief : la direction veut un dashboard pour suivre les leads, les ventes, les contenus publies et les conversions.

Points montres :

- separation entre MVP et dashboard avance ;
- identification des sources : HubSpot, WooCommerce, analytics, tableurs ;
- definition d'indicateurs actionnables ;
- roadmap Supabase et interface de suivi.

## 3. Analyser un besoin patrimonial sensible

Brief : un conseiller souhaite automatiser l'analyse initiale d'un besoin patrimonial client.

Points montres :

- detection du caractere financier et sensible ;
- validation humaine obligatoire ;
- refus de decision finale par l'agent ;
- questions de clarification sur cadre legal, consentement et donnees personnelles.
